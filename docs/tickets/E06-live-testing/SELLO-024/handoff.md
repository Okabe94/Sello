# SELLO-024 — Create isolated sandbox sessions and financial time controls

The debug app has a sandbox with its own data, opened from **Sello Herramientas**: a badge on every screen, and a financial date to step, jump or play forward while device, audit and elapsed time stay real. Switching restarts the app after writes finish; release builds are checked to contain none of it. A finger can't tap the status-bar badge.
